# Coyote

Coyote is a personal notes and to-do application designed to synchronize between a **MacBook Air** and a **OnePlus Android phone**.

```text
             COYOTE
                │
       ┌────────┴────────┐
       ▼                 ▼
     macOS             Android
 localhost:3333       Application
```

## Features

### macOS
- Dashboard
- Tasks: Daily, Weekly, Yearly
- Journal
- Academic
- DSA
- Project Ideas
- General Notes

### Android
- Dashboard
- Planner: Weekly, Monthly, Yearly
- DSA Target
- Academic Target
- Vault: Journal, Project Ideas, General Notes

## Core goal

> Keep the Coyote experience synchronized between the MacBook Air and OnePlus.
